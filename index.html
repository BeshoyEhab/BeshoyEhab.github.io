03 — OUTPUT

projects

A few of the strongest things I've built, and why I built them.

ACTIVE

hebbian-poc private repo

A Hebbian knowledge graph where edges traversed during spreading activation get their weights updated — plasticity happens at query time, not at indexing time. Most RAG systems only update on re-index; this tests whether a graph can reinforce the paths it actually uses, closer to how biological memory works. ReAct loop, fact-checking, hybrid retrieval, dream-consolidation, FastAPI + MCP server. ~13K lines.

SHIPPED

dot-man ↗ PyPI: dotman-git

A git-powered dotfile manager that treats each machine profile as a branch. Built after breaking my own configs too many times testing new Hyprland and Neovim setups — branch-per-profile means I can try something risky and switch back to a known-good state in one command. Published to PyPI, and I use it daily.
